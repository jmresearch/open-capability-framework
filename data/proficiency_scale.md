# Proficiency Scale (P1–P6)

The universal capability-side proficiency rubric: every capability in [the catalog](capabilities.md) is leveled against these six Dreyfus-derived bands, independent of any role's scope (see [scope levels](scope_levels.md)).

<a id="p1"></a>
### P1 — Assisted

*Dreyfus analog:* Novice

Entry-level professional; well-defined tasks; work reviewed; knows when to ask.

<a id="p2"></a>
### P2 — Independent

*Dreyfus analog:* Advanced beginner

Performs standard work on their own with normal review; handles routine variation.

<a id="p3"></a>
### P3 — Proficient

*Dreyfus analog:* Competent

Fully autonomous; handles ambiguity and hard cases; sets the local standard; the go-to.

<a id="p4"></a>
### P4 — Expert

*Dreyfus analog:* Proficient

Defines the approach others adopt; solves problems others can't; teaches the proficient.

<a id="p5"></a>
### P5 — Authority

*Dreyfus analog:* Expert

Recognized authority across the org; sets the standard/strategy; anticipates direction.

<a id="p6"></a>
### P6 — Pioneer

*Dreyfus analog:* Master

Defines the discipline; externally credible; shapes wider industry practice.
